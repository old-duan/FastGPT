产品功能介绍

知识库管理

多源数据接入

支持多种数据源导入知识库:

  • 文件上传: 支持 PDF、Word、Markdown、TXT 等常见格式
  • 网站抓取: 自动爬取网站内容,支持自定义选择器
  • API 接入: 通过 API 对接第三方数据源
  • 手动录入: 支持直接在系统中编辑知识条目

智能分块处理

系统会自动将长文本切分为合适的块大小,支持:

  • 自定义分块大小(256-1500 tokens)
  • 智能段落识别
  • QA 拆分模式
  • 保留上下文关联

向量化存储

将文本转换为向量,实现语义检索:

  • 支持多种 Embedding 模型
  • 高性能向量检索
  • 混合检索(向量+关键词)
  • 相似度阈值控制

应用编排

可视化工作流

通过拖拽方式编排应用流程:

  • 知识库搜索节点
  • AI 对话节点
  • 条件判断节点
  • HTTP 请求节点
  • 插件调用节点

高级功能

  • 上下文拼接: 智能组合检索结果和对话历史
  • 引用追踪: 显示答案来源,可溯源验证
  • 敏感词过滤: 自定义敏感词库,保护内容安全
  • 指定回复: 针对特定问题设置固定答案

发布与分享

多种方式发布和集成你的应用:

  • Web 链接: 生成独立访问链接,可嵌入网站
  • API 调用: 提供标准 REST API,方便系统集成
  • 微信公众号: 接入公众号,打造智能客服
  • 飞书/钉钉: 集成企业通讯工具
