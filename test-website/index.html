欢迎来到 FastGPT 测试站点

关于本站

这是一个专门用于测试 FastGPT Web 站点同步功能的极简网站。

本站包含多个页面,用于验证知识库的网站抓取和同步功能是否正常工作。

主要内容

FastGPT 是一个基于 LLM 大语言模型的知识库问答系统,提供以下核心功能:

  • 智能知识库管理
  • 多源数据接入(文件、网站、API)
  • 高质量向量检索
  • 工作流编排
  • 应用发布与分享

技术特点

系统采用现代化的技术栈构建:

  • 前端: Next.js + TypeScript + Chakra UI
  • 后端: Node.js + MongoDB + PostgreSQL
  • AI: 支持 OpenAI、Claude、国产大模型等
  • 向量数据库: pgvector
